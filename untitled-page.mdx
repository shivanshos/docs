## 🚀 Quick Start

```bash
# Clone and navigate
cd shivanshos-starter

# Option 1: Interactive menu (recommended)
chmod +x quickstart.sh
./quickstart.sh

# Option 2: Complete automated setup
chmod +x scripts/*.sh
./scripts/install-docker.sh
./scripts/install-ollama.sh
./scripts/fetch-models.sh
./scripts/install-agents.sh

# Option 3: Using Make
make install
```

## 🤖 Pre-configured Agents

1. **Hermes** (Port 8001) - Research, documentation, code generation
2. **OpenCLAW** (Port 8002) - Security scanning, code review
3. **LangChain** (Port 8003) - Sequential/parallel workflow chains
4. **vLLM** (Port 8000) - High-throughput model serving

## 📚 Key Features

- ✅ Docker installer with GPU support
- ✅ Ollama with automatic model fetching (llama3.2, mistral, codellama)
- ✅ Agent configuration templates (YAML-based)

- ✅ GitHub Actions CI/CD pipeline
- ✅ Comprehensive documentation (7 MD files)
- ✅ Environment management (.env.example)
- ✅ Make commands for common operations
- ✅ Troubleshooting guide included
