# Verification and provenance

Resource labels used in this canonical index:

| Status | Meaning |
| --- | --- |
| Publisher verified | The original publication explicitly names the relevant person or venture |
| Published | An independently accessible first-party webpage was found |
| User supplied | A link supplied by the owner; ownership and content may need checking |
| Registration evidence | Enrollment email or other account-side evidence, not proof of every public claim |
| Platform only | A platform homepage, not an individual's membership or credential |
| Inferred | A link formed from a handle or prior reference; needs destination verification |
| Pending | Missing issuer proof, ownership mapping, or original video/press source |
| Owner-declared | The owner approved the public address association; signature proof has not been verified |
| Cryptographically verified | Wallet signature checked against a domain-bound, time-limited challenge |

## Before adding a badge

Check issuer, recipient account, title, issue date, evidence URL, expiration if any and artwork usage rights. Do not combine counts across Google accounts or transfer badges by implication.

## Before adding a media reference

Check publisher, canonical URL, date, correct subject identity, attribution, and image licensing. The [Entrepreneur article](/media/entrepreneur) is verified as an editorial feature, not a confirmed print cover.

## Before adding a research paper

Match ORCID, full author name, institutional affiliation and DOI against a confirmed author record. Do not ingest similarly named authors automatically.

## Private directory exclusion

Public records intentionally exclude actual personal email addresses, Workspace admin roles, passwords, OAuth tokens, cloud resource IDs, internal network and storage details.

For published Web3 claims, follow the [wallet verification procedure](/web3/verification); do not imply token or NFT ownership from an unverified explorer link.
