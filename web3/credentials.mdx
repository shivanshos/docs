# Web3 credentials and achievements

No NFT, tokenized badge, Galxe quest credential, or attestation has been verified for this address yet. An EVM-compatible address is not, on its own, a verified membership or professional credential.

| Credential source | Status | Evidence needed |
| --- | --- | --- |
| Galxe public profile | Not linked | Actual Galxe ID profile URL |
| Galxe quests or badges | Not verified | Issuer-issued credential URL |
| NFT / tokenized badge | Not verified | Chain, contract and token ID |
| On-chain attestation | Not verified | Schema, issuer, chain and record |
| Wallet ownership | Owner-declared | Valid domain-bound signing proof |

[Galxe's official account guide](https://help.galxe.com/en/articles/9733866-introducing-galxe-account) explains how to find a Galxe ID and manage linked wallets.

This list will only display completed claims when the original issuer or public on-chain record has been checked.
